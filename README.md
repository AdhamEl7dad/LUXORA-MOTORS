# 🚗 LUXORA MOTORS
### Premium Automotive Showroom

A modern luxury automotive showroom website featuring premium vehicles, detailed specifications, interactive car collections, and an automotive photography gallery.

## 🌟 Project Overview

LUXORA MOTORS is a Multimedia University Project designed to present luxury and high-performance vehicles through an elegant and responsive website.

The project combines modern web design, interactive JavaScript functionality, automotive photography, and a Before & After photo-editing gallery.

## ✨ Features

- **30 Luxury Vehicles:** A collection of 30 vehicles from 12 international automotive brands.
- **Vehicle Details:** Detailed specifications, performance information, and vehicle descriptions.
- **Smart Search:** Search vehicles by brand and model.
- **Advanced Filtering:** Filter by brand, price, category, fuel type, and transmission.
- **Sorting Options:** Sort vehicles by price, year, and brand.
- **Featured Vehicles:** Highlighted premium automotive models.
- **Photo Gallery:** Automotive image gallery with an interactive viewer.
- **Photoshop Before & After:** Five automotive photo-editing comparison projects.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Contact Form:** Form validation and contact information.

## 🏎️ Featured Automotive Brands

Mercedes-Benz, BMW, Porsche, Audi, Ferrari, Lamborghini, Range Rover, McLaren, Rolls-Royce, Bentley, Aston Martin, and Lexus.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

For development using Vite:

```bash
npm install
npm run dev
```

To build the project:

```bash
npm run build
```

## 🎨 Photoshop Projects

The website includes five automotive image-editing themes:

1. Cinematic Color Grading
2. Background Replacement
3. Blemish & Distraction Removal
4. Dodge & Burn Enhancement
5. Automotive Poster Composition

The current Before & After images are illustrative editing examples. The final Adobe Photoshop deliverables and editable PSD files must be prepared separately.

## 📱 Responsive Design

The website is designed to provide a smooth browsing experience across desktop computers, tablets, and mobile devices.
